# 台北市非營利幼兒園往年中簽率參考

整理台北市非營利幼兒園歷年招生抽籤與中簽率相關公開資料，提供家長在報名前快速比較不同園所的錄取難度與熱門程度。

## 這個專案要解決什麼問題

- 各年度招生資訊分散，家長不容易快速比對
- 同一間園所不同年度的報名熱度可能變化，單看單年資料不夠
- 報名前需要更務實的參考依據，協助安排志願與心理預期

## 適合誰使用

- 準備報名台北市非營利幼兒園的家長
- 想比較不同行政區、不同園所歷年中簽率的人
- 想用歷年資料作為選園參考的人

## 預計整理的資料

- 園所名稱 / 行政區
- 招生年度
- 招生名額
- 報名人數
- 錄取人數
- 中簽率
- 資料來源與更新日期

## 預期使用方式

1. 依行政區或園所查詢歷年資料
2. 觀察不同年度的中簽率變化
3. 搭配招生名額與報名人數，評估報名難度

## 資料原則

- 以公開資料為主，逐筆註明來源
- 相同欄位盡量統一格式，便於後續查詢與比較
- 若原始資料有缺漏或公告方式變動，會在資料註記中說明

本專案內容僅供參考，不代表實際錄取結果，也不構成任何報名保證。最新與最終資訊請以台北市政府教育局、各園所或相關官方公告為準。
